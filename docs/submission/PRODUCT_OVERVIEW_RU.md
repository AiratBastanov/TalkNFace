# TalkNFace — «Арена переговоров»: обзор продукта

Краткий документ для человека, который не видел переписку команды. Рабочий прототип — тренажёр, где игрок выбирает действия. Живого AI в показанном продукте нет.

## Для кого

- **Игрок.** Начинающий закупщик или руководитель: нужно согласовать поставку либо нагрузку команды и можно ошибиться без цены для реальной сделки.
- **Администратор.** Задаёт контекст, проверяет и публикует ситуацию. Чужие попытки и отчёты ему не открываются.
- **Наставник.** Разбирает отчёт вместе с игроком на экране игрока. Не заменяет живого тренера и не получает отдельный доступ к попыткам.
- **Возможный покупатель.** HR / L&D как целевой сегмент. Пилотов, договоров и измеренного эффекта нет. ОЭЗ «Алабуга» — автор кейса хакатона, не клиент продукта.

## Какую проблему закрываем

Знать приём (интересы, альтернатива, пакет) недостаточно, чтобы выбрать вопрос или уступку под давлением. Лекция не создаёт этот выбор. Живой тренинг создаёт, но его трудно повторить в том же составе. Продукт даёт безопасные попытки в настроенном контексте и разбор конкретных действий.

Это гипотеза пользы, не измеренный ROI.

## Что человек делает

1. Администратор задаёт шесть полей: сфера, тема, сложность, тон, роль, цель.
2. Система подбирает и проверяет сценарий. Недостижимая цель не публикуется.
3. Игрок без регистрации фиксирует цель и свою альтернативу, затем выбирает ходы: вопрос, признание факта, довод, пакет, принятие, выход.
4. Учебный движок считает допустимость, раскрытие фактов и полезность.
5. На экране отдельно: исход сделки и разбор процесса со ссылкой на сохранённый ход.
6. «Повторить ту же ситуацию» создаёт новую попытку той же опубликованной версии.

## Две семьи сценариев

- **S1. Промышленные закупки.** Цена, график партии, предоплата. Проверенный маршрут показа: пакет 95 / 40% на день 7 и остаток на 14 / предоплата 50%, учебная полезность 64, процесс 100.
- **S2. Срочная задача и нагрузка.** Объём, срок, помощник, перенос отчёта. Проверенный маршрут: полный объём / 2 дня / помощник / перенос, полезность 47, процесс 100.

Третьей отрасли нет. Не каждая комбинация шести полей проходит проверку.

## Баллы

- Полезность сделки описывает пакет в учебной модели.
- Балл процесса описывает применимые проверки этой записи.
- 100 из 100 — не компетенция человека.
- Отказ не равен провалу процесса. Слабое соглашение не обнуляет все проверки.
- Если наблюдений мало, общий балл не выводится.

## Архитектура просто

Браузер → production Fastify + React с одного origin → детерминированные правила переговоров и разбора → SQLite. Показ слушает только 127.0.0.1. Модель, CUDA и платный API для игры не нужны.

## Зависимости запуска

Windows x64, PowerShell, Chrome. Первая установка Prepare скачивает закреплённый Node 24.21.0 и зависимости по lockfile. Дальше игра офлайн относительно внешних сервисов. Пароль администратора задаёт тот, кто готовит демо; в Git его нет.

## Границы MVP

Сделано: цикл выбора действий, две семьи, конфигурация, разбор, повтор, локальный запуск.

Не сделано в этом демо: свободный текст, AI-оппонент, генерация сценария моделью, публичный HTTPS, сертификация Linux/macOS.
