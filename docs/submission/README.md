## Запуск на Windows

Из корня с `package.json`. Первая установка качает Node и зависимости и просит свой пароль администратора. Игра после этого не требует модели и ключа API.

### 1. Подготовка и запуск

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\windows-demo.ps1 -Prepare
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\windows-demo.ps1 -Start -Port 3100
```

### 2. Открыть и пользоваться

http://127.0.0.1:3100/admin — пароль, заданный на Prepare.

Игроку: http://127.0.0.1:3100/ — регистрации нет.

Адрес работает только на компьютере, где запущен сервер. Это не удалённое демо. Пишите `127.0.0.1`, не `localhost`.

### 3. Остановить после показа

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\windows-demo.ps1 -Stop
```

Остановка сохраняет локальные попытки. Следующий Start с тем же портом их не стирает.
