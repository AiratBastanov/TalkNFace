## Запуск прототипа

Проверенные команды из корня checkout, Windows x64:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\windows-demo.ps1 -Prepare
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\windows-demo.ps1 -Start -Port 3100
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\windows-demo.ps1 -Stop
```

Админка: http://127.0.0.1:3100/admin — loopback, не публичный сайт. Пароль задаёте вы. Для игры модель и ключи не нужны.

## AI

В продемонстрированном продукте нет готовой встроенной и проверенной по качеству модели. Guided-выбор + детерминированный движок + разбор по сохранённым действиям. Обучение Qwen — отдельная историческая линия на `main`, к запуску демо не относится.
