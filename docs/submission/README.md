## Запуск кратко

Из корня репозитория (рядом с `package.json`):

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\windows-demo.ps1 -Prepare
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\windows-demo.ps1 -Start -Port 3100
```

Администратор: http://127.0.0.1:3100/admin  
Игрок: http://127.0.0.1:3100/

Остановка — отдельной командой `-Stop`. Пароль администратора вы задаёте сами при Prepare. Модель и ключ API не нужны.

## Стек

Fastify, React, SQLite. Первая подготовка скачивает Node.js 24.21.0. Игра после этого работает без внешних сервисов.
