# Показ Negotiation Arena за 3–5 минут

До показа выполните Prepare/Start из [README](../README.md), откройте http://127.0.0.1:3100/admin. Это сценарий **после установки**, а не обещание времени скачивания на любой сети. Режим guided, **без AI**: выбранные действия обрабатывает детерминированная учебная модель.

1. **0:00–1:00 — администратор.** Войдите со своим локальным паролем. В «Настроить контекст» задайте все шесть полей: сфера «Промышленные закупки», тема «Плановая поставка», сложность «Обычная», тон «Дружелюбный», роль «Директор продаж», цель «Доходность сделки». Сохраните черновик → «Подобрать и проверить сценарий» → «Предпросмотр». Проверка проверяет достижимость учебной цели; публикация требует отдельного решения.
2. **1:00–1:30 — публикация и подготовка.** Прочитайте брифинг, отметьте «Я проверил…», явно нажмите «Опубликовать», затем «Начать настроенные переговоры». Выберите свою цель, отметьте собственную альтернативу и «Сохранить подготовку». Подготовка фиксируется до первого хода; её отсутствие не даёт автоматический балл.
3. **1:30–3:00 — переговоры S1.** Начните переговоры. Задайте вопрос о логистике, признайте открытый факт об экономии на логистике, приведите логистический аргумент, спросите об оплате. Предложите **95 / 40% на день 7, остаток на день 14 / 50% предоплаты**. Проверьте и отправьте предложение. В этой настроенной ситуации проверенный путь даёт полезность 64 и полную учебную цель. Другие действия могут закончиться отказом/невыгодным соглашением; свободного текста и AI-генерации здесь нет.
4. **3:00–4:00 — обратная связь.** Покажите результат сделки отдельно от разбора процесса. Откройте измерение создания ценности и ссылку на доказательство: она ведёт к точному сохранённому действию. Для указанного подготовленного пути process score — 100; при недостатке наблюдений приложение честно не выводит общий балл. Это обратная связь по учебной модели, не диагноз навыка человека.
5. **4:00–5:00 — replay и сохранность.** Нажмите «Повторить ту же ситуацию»: создаётся новая попытка той же опубликованной версии, старая не перезаписывается. Остановите демо командой Stop и запустите Start с тем же Port; обновите вкладку в том же браузере. Действующая cookie позволяет продолжить попытку и прочитать прежний отчёт. Для короткого показа рестарт можно выполнить заранее и показать сохранённую попытку.

Дополнительная семья S2: сфера управления командой, тема срочной задачи, высокая сложность, дружелюбный тон, роль руководителя группы, цель выполнения полного объёма (IDs: team / urgent / advanced / friendly / team_lead / deliver_scope). После save/validate/preview/approve/publish/подготовки: вопросы «Приоритеты работы» → «Доступные ресурсы» → признать факт о переносе отчёта → аргумент «Связать помощь с выполнимым планом» → **полный объём / 2 дня / помощник / перенос отчёта**. Проверенная полезность — 47. Это дополнительный маршрут, не обязательная часть пяти минут.

Игрокам не нужна регистрация. В другом браузерном контексте чужой UUID не открывает попытку. После logout/истечения срока/потери cookie восстановления аккаунта в MVP нет. Перед показом можно выполнить Backup; команды хранения/восстановления описаны в README. Публичное размещение и live AI в этот показ не входят.
