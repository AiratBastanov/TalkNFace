# Показ TalkNFace за 3–5 минут

Сначала разверните прототип: [ORGANIZER_LAUNCH_RU.md](ORGANIZER_LAUNCH_RU.md). Откройте http://127.0.0.1:3100/admin.

Презентация: [PPTX](submission/TALKNFACE_PRODUCT_PITCH_RU.pptx) и [PDF](submission/TALKNFACE_PRODUCT_PITCH_RU.pdf).

Игрок выбирает действия из списка; свободный текст в этой версии не используется.

1. **Администратор.** Войдите со своим паролем. В «Настроить контекст» задайте шесть полей: сфера «Промышленные закупки», тема «Плановая поставка», сложность «Обычная», тон «Дружелюбный», роль «Директор продаж», цель «Доходность сделки». Сохраните черновик → «Подобрать и проверить сценарий» → «Предпросмотр» → отметьте проверку и **Опубликовать**.
2. **Подготовка игрока.** «Начать настроенные переговоры». Выберите цель, отметьте свою альтернативу, сохраните подготовку.
3. **Переговоры.** Вопрос о логистике → признать факт об экономии → логистический довод → вопрос об оплате → пакет **95 / 40% на день 7, остаток на 14 / предоплата 50%**. Проверьте и отправьте.
4. **Разбор.** Покажите исход сделки отдельно от процесса. Откройте ссылку на сохранённый ход.
5. **Повтор.** «Повторить ту же ситуацию» создаёт новую попытку той же версии. Stop и повторный Start сохраняют данные.

Числа 64 и 70 на слайдах относятся к эталону «Закупка к запуску», не обязательно к полям этого живого показа.

Дополнительно S2: сфера управления командой, срочная задача, полный объём / 2 дня / помощник / перенос отчёта.

Регистрации игрока нет. Пишите `127.0.0.1`, не `localhost`.
